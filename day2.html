Inspecting Your FASTQ Files

Navigate to your data directory and look at what you downloaded:

bash
cd ~/dc_workshop/00_data
ls -lh

A FASTQ file has 4 lines per read. Decompress a copy to inspect:

bash
mkdir unzipped
cp SRR2589044_1.fastq.gz unzipped/
cd unzipped
gunzip SRR2589044_1.fastq.gz

head SRR2589044_1.fastq       # first few lines
tail SRR2589044_1.fastq       # last few lines
less SRR2589044_1.fastq       # scroll through (q to quit, / to search)

Search for low-quality reads (10 or more unknown bases):

bash
grep NNNNNNNNNN SRR2589044_1.fastq | wc -l     # count bad reads
grep NNNNNNNNNN SRR2589044_1.fastq > bad_reads.txt
The FASTQ Format
LineContentExample
1Read name (starts with @)@SRR2584853.1
2DNA sequenceACGTACGT...
3Separator+
4Quality scores (ASCII encoded)IIIIIHFEE...

Quality scores are Phred scores encoded as ASCII characters. A score of 30 means a 1-in-1000 chance of error (99.9% accurate).

Quality Control: FastQC & MultiQC

FastQC generates a per-sample QC report. MultiQC combines all reports into one HTML file.

bash
cd ~/dc_workshop

# Load and run FastQC on all raw reads
module load fastqc
fastqc -t 4 00_data/*.fastq.gz

# Organize the output
mv 00_data/*fastqc* 01_qc/
cd 01_qc
mkdir fastqc_untrimmed
mv *_fastqc* fastqc_untrimmed/

# Combine all FastQC reports
module load python
multiqc fastqc_untrimmed/*

# Rename so we can compare with post-trim report later
mv multiqc_data fastqc_untrimmed/
mv multiqc_report.html multiqc_report_untrimmed.html

Download the .html files via OnDemand and open them in your browser. Which sample has the best per-base sequence quality? Which looks the worst?

Trimming Reads with fastp

fastp removes low-quality bases from read ends and filters out poor-quality reads. Download and configure it:

bash
cd ~/dc_workshop/02_trimmed_reads
wget http://opengene.org/fastp/fastp
chmod u+x fastp     # make it executable
./fastp             # test that it runs

Run fastp on one file first

bash
./fastp \
  -i ~/dc_workshop/00_data/SRR2584853_1.fastq.gz \
  -o SRR2584853.trim.fastq.gz \
  -h SRR2584853.html \
  -q 30 \
  --unqualified_percent_limit 10 \
  --reads_to_process 500000

Use a loop to run fastp on all samples

bash
# Simple loop — prints each sample name
for file in ~/dc_workshop/00_data/*_1.fastq.gz; do
  base=$(basename $file _1.fastq.gz)
  echo $base
done

# Full loop — runs fastp on each sample
for file in ~/dc_workshop/00_data/*_1.fastq.gz; do
  base=$(basename $file _1.fastq.gz)
  echo "Processing $base..."
  ./fastp \
    -i $file \
    -o ${base}.trim.fastq.gz \
    -h ${base}.html \
    -q 30 -u 10 \
    --reads_to_process 500000
done
