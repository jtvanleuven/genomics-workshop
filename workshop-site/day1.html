Command Line & Data Download

Intro, data organization, command line basicsServer: marvin / zaphod.hpc.uidaho.edu:8000
Background: The LTEE Dataset

We're working with E. coli genome data from the Long-Term Evolution Experiment (LTEE). Richard Lenski has been growing E. coli populations since 1988, and genomes have accumulated mutations over tens of thousands of generations. Our six samples come from different LTEE lineages at different time points — by calling variants, we can see exactly which mutations arose and in which genes.

Setting Up Your Directory Structure

Everything lives inside a single project folder called dc_workshop. Create it and navigate in:

bash
mkdir dc_workshop
cd dc_workshop
mkdir 00_data

The full structure we'll build over the workshop:

bash
~/dc_workshop/
├── 00_data/             # raw .fastq.gz files
├── 01_qc/               # FastQC and MultiQC reports
├── 02_trimmed_reads/    # fastp output
├── 03_ref_genome/       # E. coli reference genome
├── 04_alignments/       # SAM, BAM files
└── 05_genomic_variants/ # VCF files

HPC Note

The HPC does not have man pages. Use --help instead: e.g. ls --help

Downloading the Sequencing Reads

Navigate into your data directory and download all six E. coli FASTQ files. Each file may take ~15 minutes.

bash
cd ~/dc_workshop/00_data

curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/004/SRR2589044/SRR2589044_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/003/SRR2584863/SRR2584863_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/006/SRR2584866/SRR2584866_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/003/SRR2584853/SRR2584853_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR617/002/SRR6178302/SRR6178302_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR617/002/SRR6178292/SRR6178292_1.fastq.gz
If curl fails

Substitute wget — replace curl -O with wget for each line.

Running Downloads in a screen Session

Use screen so downloads keep running if you get disconnected:

bash
screen -S downloads    # create a named session
# ... start your downloads ...
# Ctrl+A then D          to detach (session keeps running)
screen -r downloads    # re-attach later
