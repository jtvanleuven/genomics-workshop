🦠 Background: The LTEE Dataset

We're working with E. coli genome data from the Long-Term Evolution Experiment (LTEE) — one of the longest-running evolution experiments ever conducted. Richard Lenski has been growing E. coli populations since 1988, and the genomes have accumulated mutations over tens of thousands of generations.

Our six samples come from different LTEE lineages at different time points. By calling variants, we can see exactly which mutations arose and in which genes.

🗂️ Setting Up Your Directory Structure

Everything we do lives inside a single project folder called dc_workshop. Create it and navigate into it:

mkdir dc_workshop
cd dc_workshop
mkdir 00_data

The full directory structure we'll build over the workshop:

~/dc_workshop/
├── 00_data/          # raw .fastq.gz files
├── 01_qc/            # FastQC and MultiQC reports
├── 02_trimmed_reads/ # fastp output
├── 03_ref_genome/    # E. coli reference genome
├── 04_alignments/    # SAM, BAM files
└── 05_genomic_variants/ # VCF files

⬇️ Downloading the Sequencing Reads

Navigate into your data directory and download all six E. coli FASTQ files. Each file may take ~15 minutes.

cd ~/dc_workshop/00_data

curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/004/SRR2589044/SRR2589044_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/003/SRR2584863/SRR2584863_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/006/SRR2584866/SRR2584866_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR258/003/SRR2584853/SRR2584853_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR617/002/SRR6178302/SRR6178302_1.fastq.gz
curl -O ftp://ftp.sra.ebi.ac.uk/vol1/fastq/SRR617/002/SRR6178292/SRR6178292_1.fastq.gz
⚠️ If curl fails, substitute wget — just replace curl -O with wget.

Running downloads in a persistent screen session

Downloads can take a while. Use screen so they keep running if you get disconnected:

screen -S downloads   # create a named session
# ... start your downloads ...
# Ctrl+A then D         to detach (session keeps running)
screen -r downloads   # re-attach later
