Annotating Variants with Gene Info AI
🤖 AI Prompt — copy and paste into Claude.ai or ChatGPT
I have an R data frame "variants" with a column POS (genomic position) for E. coli variants. I'll download a GFF annotation file using ape::read.gff(). Write R code to: (1) download the GFF from ftp://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/017/985/GCA_000017985.1_ASM1798v1/GCA_000017985.1_ASM1798v1_genomic.gff.gz and save to "data/Rel606.gff.gz"; (2) read it and filter to CDS features; (3) extract gene name and product from the attributes column using str_extract() and str_remove(); (4) for each variant, find which CDS it falls within and add gene and product columns — label intergenic variants as "intergenic". Use a for loop with if/else.
R
url <- "ftp://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/017/985/GCA_000017985.1_ASM1798v1/GCA_000017985.1_ASM1798v1_genomic.gff.gz"
download.file(url = url, destfile = "data/Rel606.gff.gz")
gff <- read.gff("data/Rel606.gff.gz")

cds <- gff %>% filter(type == "CDS")
cds$gene    <- str_remove(str_split(str_extract(cds$attributes, "gene=.*?;"),    "=", simplify=T)[,2], ";")
cds$product <- str_remove(str_split(str_extract(cds$attributes, "product=.*?;"), "=", simplify=T)[,2], ";")

variants$gene <- NA; variants$product <- NA
for (i in 1:nrow(variants)) {
  match <- cds %>% filter(start < variants$POS[i], end > variants$POS[i]) %>% select(gene, product)
  if (nrow(match) > 0) {
    variants[i, c('gene','product')] <- match
  } else {
    variants[i, c('gene','product')] <- c('', 'intergenic')
  }
}
Tile Plot & Heatmap AI
🤖 AI Prompt — copy and paste into Claude.ai or ChatGPT

R
tile_plot <- ggplot(variants, aes(x = gene, y = ID)) +
  geom_tile() + theme_bw() +
  theme(axis.text.x = element_blank(), axis.ticks.x = element_blank()) +
  labs(title = "Mutations per Gene per Sample", x = "Gene", y = "Sample")

ggsave(tile_plot, file = "plots/tile.png", width = 6, height = 3, units = "in")
