🔬 Reading a VCF File

First, read a single VCF file to understand its structure:

# Basic read — treats it like a table
vcf <- read.table("data/vcfs/SRR2584853_final_variants.vcf")
head(vcf)
dim(vcf)
str(vcf)

# Better: use vcfR for structured access
vcf <- read.vcfR("data/vcfs/SRR2584853_final_variants.vcf")
vcf_clean <- vcfR2tidy(vcf)
vcf_data <- vcf_clean$fix    # the variant table
rm(vcf, vcf_clean)           # keep the environment clean

🔄 Combining All Samples with a Loop

We need to read all 6 VCF files and combine them into one data frame. This is a perfect case for AI — the loop structure is specific and error-prone to write by hand:

🤖 AI Prompt

Write R code that reads all VCF files in the directory "data/vcfs/" using the vcfR package, extracts the variant table from each, adds a column called "ID" with the sample name (extracted from the filename, everything before the first underscore), and combines all samples into a single data frame called combined_vcfs. Use a for loop. Remove intermediate objects to keep the environment clean. Show how to verify all 6 samples are represented using table().

What the loop looks like

files <- list.files("data/vcfs")

# Create empty data frame with the right columns
ncol(vcf_data)  # check how many columns first
combined_vcfs <- data.frame(matrix(ncol = 25))
names(combined_vcfs) <- names(vcf_data)

for (i in 1:length(files)) {
  file <- files[i]
  vcf <- read.vcfR(paste("data/vcfs/", file, sep = ""))
  vcf_clean <- vcfR2tidy(vcf)
  vcf_data <- vcf_clean$fix
  vcf_data$ID <- str_split(file, "_", simplify = T)[1]  # sample name
  rm(vcf, vcf_clean, file)
  combined_vcfs <- rbind(combined_vcfs, vcf_data)
}

# Remove the empty first row
combined_vcfs <- combined_vcfs %>%
  filter(!is.na(CHROM))

table(combined_vcfs$ID)   # verify all 6 samples present

🔧 Wrangling the Variant Data

Select the columns we care about and calculate basic summaries:

names(combined_vcfs)    # see all available columns

variants <- combined_vcfs %>%
  select(ID, POS, REF, ALT, QUAL, INDEL, DP, MQ)

dim(variants)
mean(variants$DP)    # average read depth across all variants

# Count variants per sample
cnt_tab <- variants %>%
  group_by(ID) %>%
  summarize(tot_muts = n()) %>%
  arrange(desc(tot_muts))
