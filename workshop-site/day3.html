Post-Trim Quality Control

Run FastQC and MultiQC on the trimmed reads to compare before and after:

bash
cd ~/dc_workshop/01_qc/
mkdir fastqc_trimmed

module load fastqc
fastqc ~/dc_workshop/02_trimmed_reads/*.fastq.gz -o ./fastqc_trimmed/

module load python

The Variant Calling Pipeline

Today we go through the pipeline one sample at a time (SRR2584863). Tomorrow we automate it for all six with a bash script.

FormatToolPurpose
.samBWA memHuman-readable alignment of reads to genome
.bamsamtools viewCompressed binary version of SAM
.bam (sorted)samtools sortReads ordered by genomic position
.bam.baisamtools indexIndex file needed for IGV and variant calling
.bcfbcftools mpileupPer-position read coverage
.vcfbcftools callCalled SNP variants
.vcf (filtered)vcfutils.plHigh-quality variants only

Step 1 — Download & index the reference genome

bash
cd ~/dc_workshop/03_ref_genome/

wget ftp://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/017/985/GCA_000017985.1_ASM1798v1/GCA_000017985.1_ASM1798v1_genomic.fna.gz

mv GCA_000017985.1_ASM1798v1_genomic.fna.gz rel606.fasta.gz
gunzip rel606.fasta.gz

module load bwa
bwa index rel606.fasta

Step 2 — Align reads (BWA)

bash
bwa mem ~/dc_workshop/03_ref_genome/rel606.fasta \
  ~/dc_workshop/02_trimmed_reads/SRR2584863.trim.fastq.gz \
  > SRR2584863.aligned.sam

cd ~/dc_workshop/04_alignments
mkdir sam
mv ~/dc_workshop/03_ref_genome/SRR2584863.aligned.sam ./sam/

Step 3 — Convert SAM → BAM, sort, index

bash
module load samtools
cd ~/dc_workshop/04_alignments/sam

samtools view -S -b SRR2584863.aligned.sam > ../bam/SRR2584863.aligned.bam
samtools sort -o ../bam/SRR2584863.aligned.sorted.bam ../bam/SRR2584863.aligned.bam
samtools index ../bam/SRR2584863.aligned.sorted.bam ../bam/SRR2584863.aligned.sorted.bam.bai

Step 4 — Call variants (BCFtools)

bash
cd ~/dc_workshop/05_genomic_variants
mkdir vcf

module load bcftools

bcftools mpileup -O b \
  -o SRR2584863_raw.bcf \
  -f ~/dc_workshop/03_ref_genome/rel606.fasta \
  ~/dc_workshop/04_alignments/bam/SRR2584863.aligned.sorted.bam

bcftools call --ploidy 1 -m -v \
  -o ./vcf/SRR2584863.vcf \
  SRR2584863_raw.bcf

cd vcf
vcfutils.pl varFilter SRR2584863.vcf > SRR2584863_final_variants.vcf
less -S SRR2584863_final_variants.vcf
