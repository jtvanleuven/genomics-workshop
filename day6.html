🔬 Merging with Metadata

The LTEE metadata tells us how many generations each strain was evolved. Merging it with our variant counts lets us ask: do strains with more generations have more mutations?

🤖 AI Prompt

I have two R data frames. The first, "cnt_tab", has columns "ID" (E. coli sample name like SRR2584853) and "tot_muts" (total number of SNP variants). The second is metadata I'll download from this URL: https://raw.githubusercontent.com/datacarpentry/wrangling-genomics/gh-pages/files/Ecoli_metadata_composite.csv — it has a column "run" with the sample name and a column "generation" with the number of generations evolved. Write R code to: 1. Download and read the metadata CSV 2. Merge it with cnt_tab by matching ID to run 3. Make a line plot (ggplot2) of mutations over evolutionary time: generation on x-axis, tot_muts on y-axis, with points and a line connecting them 4. Add informative axis labels and a title

# Download and read metadata
url <- "https://raw.githubusercontent.com/datacarpentry/wrangling-genomics/gh-pages/files/Ecoli_metadata_composite.csv"
download.file(url = url, destfile = "data/Ecoli_metadata_composite.csv")
meta <- read.csv("data/Ecoli_metadata_composite.csv")

# Merge with mutation counts
cnt_tab_meta <- merge(cnt_tab, meta, by.x = "ID", by.y = "run")
View(cnt_tab_meta)

# Plot: mutations over evolutionary time
ggplot(cnt_tab_meta, aes(x = generation, y = tot_muts)) +
  geom_line() +
  geom_point() +
  labs(x = "Generations Evolved", y = "Number of Mutations",
       title = "Mutation Accumulation in E. coli LTEE Strains") +
  theme_bw()

🧬 Annotating Variants with Gene Information

Download the GFF annotation file and label each variant with the gene it falls in:

🤖 AI Prompt

I have an R data frame called "variants" with genomic variant positions (column POS) from E. coli. I also have a GFF annotation file I can read with ape::read.gff(). Write R code to: 1. Download the GFF from: ftp://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/017/985/GCA_000017985.1_ASM1798v1/GCA_000017985.1_ASM1798v1_genomic.gff.gz and save it to "data/Rel606.gff.gz" 2. Read it and filter to only CDS features 3. Extract the gene name and product name from the attributes column using str_extract() and str_remove() 4. For each row in variants, find which CDS the position falls within (between start and end), and add gene and product columns to variants. If the position is between genes, label it "intergenic". Use a for loop with an if/else to handle the intergenic case.

# Download and read GFF annotation
url <- "ftp://ftp.ncbi.nlm.nih.gov/genomes/all/GCA/000/017/985/GCA_000017985.1_ASM1798v1/GCA_000017985.1_ASM1798v1_genomic.gff.gz"
download.file(url = url, destfile = "data/Rel606.gff.gz")
gff <- read.gff("data/Rel606.gff.gz")

# Extract CDS features
cds <- gff %>% filter(type == "CDS")

# Parse gene name and product from the attributes column
cds$gene    <- str_remove(str_split(str_extract(cds$attributes, "gene=.*?;"), "=", simplify = T)[,2], ";")
cds$product <- str_remove(str_split(str_extract(cds$attributes, "product=.*?;"), "=", simplify = T)[,2], ";")

# Annotate each variant with gene info
variants$gene    <- NA
variants$product <- NA

for (i in 1:nrow(variants)) {
  match <- cds %>%
    filter(start < variants$POS[i], end > variants$POS[i]) %>%
    select(gene, product)
  if (nrow(match) > 0) {
    variants[i, c('gene','product')] <- match
  } else {
    variants[i, c('gene','product')] <- c('', 'intergenic')
  }
}

🔥 Heatmap with pheatmap

Create a gene expression-style heatmap using simulated expression data based on real LTEE gene names:

🤖 AI Prompt

I have a vector of real E. coli gene names from the Rel606 genome stored in a data frame called "cds" (column: gene). Write R code using the pheatmap package to: 1. Randomly sample 500 gene names from cds (filter out genes with no name first) 2. Create a simulated expression matrix (500 genes x 6 samples) with random normal data (mean=8, sd=3) 3. Add a biological signal: add 6 to the expression values of the first 20 genes in samples 1-3 (these represent "citrate-utilizing" strains) 4. Add column annotations marking samples 1-3 as "citrate" and 4-6 as "nocitrate" 5. Generate a pheatmap with: row scaling, correlation-based clustering, a blue-white-red color scheme, and a title The 6 sample names are: SRR2584853, SRR2584863, SRR2584866, SRR2589044, SRR6178292, SRR6178302

library(pheatmap)

# Sample real gene names
set.seed(123)
ngenes <- 500
sample_genes <- cds %>%
  filter(!gene == "") %>%
  slice_sample(n = ngenes) %>%
  select(gene, product)

# Simulated expression matrix
exp_data <- matrix(rnorm(600, mean = 8, sd = 3), nrow = ngenes, ncol = 6)
colnames(exp_data) <- c("SRR2584853","SRR2584863","SRR2584866",
                         "SRR2589044","SRR6178292","SRR6178302")
rownames(exp_data) <- sample_genes$gene

# Add biological signal for citrate strains
exp_data[1:20, 1:3] <- exp_data[1:20, 1:3] + 6

# Column annotations
col_ann <- data.frame(Condition = rep(c("citrate","nocitrate"), each = 3))
rownames(col_ann) <- colnames(exp_data)

# Heatmap
pheatmap(exp_data,
         main = "Rel606 Gene Expression Analysis",
         annotation_col = col_ann,
         scale = "row",
         clustering_distance_rows = "correlation",
         color = colorRampPalette(c("#053061","#f7f7f7","#67001f"))(100),
         fontsize_row = 7)
