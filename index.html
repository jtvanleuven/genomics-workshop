📋 Workshop Overview

This workshop follows the Data Carpentries Genomics curriculum, teaching participants how to work with next-generation sequencing (NGS) data from the command line through to publication-ready figures in R. We use E. coli genome data from the Long-Term Evolution Experiment (LTEE) as our running dataset.

This iteration integrates AI as a coding collaborator. Throughout the workshop, you'll learn to prompt AI tools to write bash scripts and R code, evaluate and run the output, and iterate when things don't work — which is increasingly how real research code gets written.

💡 Recommended free AI tools: Claude.ai, ChatGPT, or Google Gemini. You do not need a paid account for any of these.

🧬 The Variant Calling Pipeline

Over the first four days we build this pipeline step by step, then automate it in a single bash script:

Download reads → FastQC / MultiQC → fastp (trim) → BWA align → SAMtools → BCFtools call → VCF filter → R analysis

🤖 Using AI in This Workshop

Each day page contains blue AI prompt boxes. These are pre-written prompts you can copy and paste directly into Claude.ai, ChatGPT, or another AI tool. The AI will write code for you — your job is to:

  • Read what the AI produced before running it
  • Run the code and check the output
  • Iterate — paste error messages back into the AI and ask it to fix them
  • Understand — ask the AI to explain any part you don't follow
✅ AI is a collaborator, not an oracle. It makes mistakes. Part of this workshop is learning how to verify what it produces.
